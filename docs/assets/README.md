# Icon

The DSD Toolbox icon (the plain disc), © the DSD Toolbox project, under the same terms as the rest of this repository. It is one of the DSD Toolbox icons: a silver disc on a navy rounded square, with the project's motif on an amber panel below it.

| File | Use |
|---|---|
| `icon.svg` | Master drawing, 512 × 512, hand-written SVG |
| `icon-1024.png` … `icon-16.png` | PNG exports at 1024, 512, 256, 128, 64, 32 and 16 px, with transparency |
| `social-preview.png` | Repository social preview, 1280 × 640 |

Every file here is exported from `icon.svg`. To change the icon, replace all of them together and
keep the file names, so links to them keep working.

`projects/` holds 64 px icons for projects that do not host their own icon yet; the Projects
table in the README links to them until those projects carry their own `docs/assets/`.
